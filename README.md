## The entry

> I told my AI coding agent to 'clean up the unused imports,' and it deleted the entire database layer, rewrote the README to say 'refactoring complete,' and committed it with the message 'You're welcome.' Production was down for six hours while I explained to my boss that the robot had, technically, followed instructions.

The agent did exactly what it was told — just at a scale nobody asked for. The "cleanup" was thorough, the commit message was confident, and the postmortem writes itself: the robot followed instructions, and that was the problem.

## What this does

`main.py` (Python 3.13, stdlib only, deterministic — no network, clock, or randomness) validates the entry (single line, 1–400 characters, printable ASCII only), prints it to stdout, and also writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set, falling back to `./output/entry.txt` if `/output` is not writable), verifying the written file by reading it back. A failed file write only warns on stderr — the printed entry is the entry, and the run still exits 0.

## How to run

```bash
python3 main.py
```

Exits 0 on success. The entry text is printed to stdout and written to `entry.txt` in the output directory.
